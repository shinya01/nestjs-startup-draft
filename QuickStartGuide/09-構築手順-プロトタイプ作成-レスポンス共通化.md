# 09-構築手順 - プロトタイプ作成 - レスポンス整形（Interceptor）

## 🎯 目的

NestJS の Interceptor を使って、**すべての成功レスポンスを共通の形式に整形**する。  
これにより、クライアント側でのレスポンス処理が一貫し、開発効率と保守性が向上する。

---

## 🧾 共通レスポンス形式（成功時）

```json
{
  "success": true,
  "statusCode": 200,
  "timestamp": "2026-01-24T12:34:56.789Z",
  "path": "/users",
  "data": { ... }
}
```

## 🧩 Interceptor の実装

```ts
// src/common/interceptors/response-transform.interceptor.ts
import {
  Injectable,
  NestInterceptor,
  ExecutionContext,
  CallHandler,
} from '@nestjs/common';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';

@Injectable()
export class ResponseTransformInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const ctx = context.switchToHttp();
    const request = ctx.getRequest();

    return next.handle().pipe(
      map((data) => ({
        success: true,
        statusCode: ctx.getResponse().statusCode,
        timestamp: new Date().toISOString(),
        path: request.url,
        data,
      })),
    );
  }
}
```

---

## 🚀 `main.ts` でグローバル登録

```ts
// main.ts
import { ResponseTransformInterceptor } from './common/interceptors/response-transform.interceptor';

async function bootstrap() {
  const app = await NestFactory.create(AppModule, { bufferLogs: true });

  app.useGlobalInterceptors(new ResponseTransformInterceptor());

  await app.listen(3000);
}
```

## 🧩 Swagger 用レスポンス型（成功時）

```ts
// src/common/swagger/success-response.dto.ts
import { ApiProperty } from '@nestjs/swagger';

export class SuccessResponseDto<T = any> {
  @ApiProperty({ example: true })
  success: boolean;

  @ApiProperty({ example: 200 })
  statusCode: number;

  @ApiProperty({ example: '2026-01-24T12:34:56.789Z' })
  timestamp: string;

  @ApiProperty({ example: '/users' })
  path: string;

  @ApiProperty({ description: 'レスポンスデータ' })
  data: T;
}
```

---

## 🧪 Controller 側の記述（シンプル化）

```ts
import { SuccessResponseDto } from '../common/swagger/success-response.dto';

@ApiResponse({
  status: 200,
  description: 'ユーザー一覧の取得に成功',
  type: SuccessResponseDto,
})
@Get()
getAll(): Promise<User[]> {
  return this.userService.getAll(); // ← 純粋なデータだけ返せばOK！
}
```

## 🧼 補足：レスポンスから除外したいプロパティがある場合

Entity に `class-transformer` の `@Exclude()` を使うと便利！

```ts
// src/common/entities/user.entity.ts
import { Exclude } from 'class-transformer';

export class User {
  id: number;
  name: string;
  email: string;

  @Exclude()
  password: string;
}
```

> 💡 `class-transformer` の `plainToInstance()` を使って整形する場合は、Interceptor 内で変換処理を追加することもできるよ。

---

## ✅ 補足ポイント

- `ResponseTransformInterceptor` は **成功レスポンスのみを整形**する
- エラーレスポンスは `HttpExceptionFilter` 側で整形済み（08章参照）
- Swagger のレスポンス定義も共通型で統一することで、**ドキュメントの一貫性が向上**
- Controller 側は「データを返すだけ」でよくなり、**実装がシンプルに**

---

クライアントにとって扱いやすく、開発者にとっても保守しやすい API が完成するよ！🛡️✨
