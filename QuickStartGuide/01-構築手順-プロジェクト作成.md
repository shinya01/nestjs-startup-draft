# 01-構築手順 - プロジェクト作成

## 🎯 目的

NestJS を DevContainer 上に導入し、初期状態で動作する開発環境を構築します。  
[公式ドキュメント](https://docs.nestjs.com/first-steps) の「First Steps」の内容を DevContainer 上で再現することを目標とします。

---

## 🛠️ 構築手順

### 1. DevContainer の設定

本プロジェクトをクローンまたはダウンロードし、VS Code で開きます。  
**※この時点ではまだ DevContainer を起動（Reopen in Container）しないでください。**

#### `.devcontainer/docker-compose.yml` の編集

ご自身の PC アーキテクチャに合わせて `ARCH` 引数を指定します。

```yaml
  args:
    - NODE_VER=25
    # Apple Silicon (M1/M2/M3) の場合は 'aarch64'
    # Intel/AMD プロセッサの場合は 'x86_64' を指定
    - ARCH=aarch64
```

---

### 2. DevContainer の起動

設定完了後、VS Code 右下のポップアップ、またはコマンドパレット（`Ctrl+Shift+P` / `Cmd+Shift+P`）から **「Dev Containers: Reopen in Container」** を選択し、環境を起動します。

---

### 3. NestJS プロジェクトの作成

DevContainer 内のターミナル（`/workspaces/プロジェクト名`）で以下のコマンドを実行します。

```bash
# Nest CLIが未インストールの場合は先に実行
# npm install -g @nestjs/cli

nest new sample-project
```

- パッケージマネージャーは `npm` を選択。
- **注意：** ここで作成する `sample-project` は一時的なディレクトリです。

---

### 4. プロジェクトファイルの展開

作成された `sample-project` 内のファイルをルートディレクトリへ移動します。

```bash
# 隠しファイルを含めて移動を有効化
shopt -s dotglob

# sample-projectの中身をカレントディレクトリへ移動（上書き確認が出た場合は n を推奨）
mv -n sample-project/* .

# 移動が完了したら一時ディレクトリを削除
shopt -u dotglob
rm -rf sample-project
```

> **⚠️ 注意** > `mv` 実行時に `.devcontainer` や `docker-compose.yml` などの上書き確認が出た場合は、**既存の設定（DevContainer側）を維持するため `n`（No）** を選択してください。

---

### 5. バージョンの固定 (Volta)

チーム間で Node.js と npm のバージョンを統一するため、`volta` を使用して固定します。

```bash
volta pin node
volta pin npm
```

---

### 6. VS Code デバッグ設定の作成

プロジェクトルートに `.vscode` フォルダを作成し、`launch.json` を以下の内容で作成します。

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Debug Nest Framework",
      "runtimeExecutable": "npm",
      "runtimeArgs": ["run", "start:dev"],
      "cwd": "${workspaceFolder}",
      "sourceMaps": true,
      "console": "integratedTerminal",
      "env": {
        "LOG_TYPE": "console"
      }
    }
  ]
}
```

---

### 7. Git リポジトリの再設定

既存のリモート設定を整理し、新しいリポジトリを登録します。

```bash
# 既存のリモート（テンプレート等）を削除して新しく追加する場合
git remote remove origin
git remote add origin <新しいリポジトリURL>

# 初回コミットとプッシュ
git add .
git commit -m "chore: initial nestjs project setup"
git push -u origin main
```

---

## ✅ 動作確認

1. VS Code の「実行とデバッグ」から `Debug Nest Framework` を実行します。
2. ターミナルに `Nest application successfully started` と表示されることを確認します。
3. ブラウザで `http://localhost:3000` にアクセスし、"Hello World!" が表示されれば完了です。
