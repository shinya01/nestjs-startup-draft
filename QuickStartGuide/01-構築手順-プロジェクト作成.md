# 01-構築手順 - プロジェクト作成

## 🎯 目標
NestJS を導入し、初期状態で DevContainer 上で動作する環境を構築する。  
[公式導入手順](https://docs.nestjs.com/first-steps) の「First Steps」を DevContainer 上で再現する。

---

## 🛠️ 構築・実装手順

### 1. DevContainer の設定

本プロジェクトをダウンロード、または `git clone` してローカルの VS Code で開く。  
**この時点では DevContainer を起動しないこと！**  
まずは使用する PC 環境に合わせて DevContainer の設定を行う。

#### 設定ファイルの編集

`.devcontainer/docker-compose.yml` を開き、以下のように環境に合わせて編集：

```yaml
  args:
    - NODE_VER=25
    ## x86_64 または aarch64 を指定
    - ARCH=aarch64
```

---

### 2. DevContainer の起動

設定が完了したら、VS Code で DevContainer を起動する。

---

### 3. NestJS 導入および初期設定

DevContainer 起動後、以下のコマンドで NestJS プロジェクトを作成：

```bash
nest new sample-project
```

- パッケージマネージャーの選択では `npm` を選択。
- **プロジェクト名は後から変更が難しいため慎重に決定すること！**  
  （変更する場合は、設定ファイル内の名称を `grep` して一括置換するなどの対応が必要）

---

### 4. NestJS ファイルのルートディレクトリへの移動

作成されたプロジェクトの中身をルートディレクトリに移動：

```bash
shopt -s dotglob
mv sample-project/* .
shopt -u dotglob
rm -rf sample-project
```

※ `.git` ディレクトリが移動できなくても問題なし。

---

### 5. Node.js / npm のバージョン固定

`volta` を使用してバージョンを固定：

```bash
volta pin node
volta pin npm
```

---

### 6. VS Code のデバッグ設定

プロジェクトルートに `.vscode` フォルダを作成し、`launch.json` を以下の内容で作成：
```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Debug Nest Framework",
      "runtimeExecutable": "npm",
      "runtimeArgs": ["run", "start:debug"],
      "cwd": "${workspaceFolder}",
      "sourceMaps": true,
      "console": "integratedTerminal",
      "env": {
        "LOG_TYPE": "console"
      }
    }
  ]
}
```

作成後、VS Code のデバッグ機能で NestJS が起動することを確認。

---

### 7. プロジェクト専用 Git リポジトリへの登録

既存のリモートリポジトリを削除し、新しいリポジトリを登録して push：

```bash
git remote rename origin old-origin
git remote rm old-origin
git remote add origin <新しいURL>
git add .
git commit -m "initial commit"
git push origin master
```
