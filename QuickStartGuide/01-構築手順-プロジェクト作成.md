# 01-構築手順-プロジェクト作成

## 🎯 目的

NestJS を DevContainer 上に導入し、初期状態で動作する開発環境を構築します。
[NestJS公式ドキュメント](https://docs.nestjs.com/first-steps) の「First Steps」の内容を DevContainer 上で再現することを目標とします。

## 📂 この章で作成・修正するファイル

この章の作業完了時には、以下のディレクトリ構成となります。

```text
.
├── .devcontainer/
│   └── docker-compose.yml (修正)
├── .vscode/
│   └── launch.json (新規作成)
├── src/ (NestJS プロジェクトファイル一式)
├── package.json
├── nest-cli.json
├── tsconfig.json
└── (その他 NestJS 初期生成ファイル)
```

---

## 🛠️ 構築手順

### 1. DevContainer の設定変更

まず、ご自身の PC 環境（CPUアーキテクチャ）に合わせて Docker の設定を調整します。
※この時点では、まだ DevContainer を起動（Reopen in Container）しないでください。

#### `.devcontainer/docker-compose.yml` の編集

使用している PC に応じて `ARCH` の値を変更してください。

- Mac (M1/M2/M3など): `aarch64`
- Windows / Intel Mac: `x86_64`

```yaml
  args:
    - NODE_VER=25
    # 使用環境に応じて 'x86_64' または 'aarch64' を指定
    - ARCH=aarch64
```

### 2. DevContainer の起動

設定を保存後、VS Code のコマンドパレット（`Ctrl+Shift+P` / `Cmd+Shift+P`）から以下の項目を選択し、コンテナを起動します。

- **「Dev Containers: Reopen in Container」**

### 3. NestJS プロジェクトの作成

コンテナ内のターミナルが起動したら、NestJS の新規プロジェクトを作成します。

```bash
nest new sample-project
```

- パッケージマネージャーは **`npm`** を選択してください。
- **注意:** プロジェクト名は後からの変更が難しいため、慎重に決定してください。

### 4. プロジェクトファイルの配置調整

作成された `sample-project` フォルダ内の中身を、現在のルートディレクトリへ移動させます。

```bash
# 隠しファイルを含めて移動
shopt -s dotglob
mv sample-project/* .
shopt -u dotglob

# 空になったディレクトリを削除
rm -rf sample-project
```

> ※ `.git` ディレクトリを移動させる必要はありません。

### 5. 実行環境のバージョン固定 (Volta)

プロジェクトで使用する Node.js と npm のバージョンを固定します。

```bash
volta pin node
volta pin npm
```

### 6. VS Code デバッグ設定の作成

VS Code から直接デバッグ実行ができるよう、設定ファイルを作成します。

#### `.vscode/launch.json`

プロジェクト直下に `.vscode` フォルダを作成し、以下の内容で保存してください。

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Debug Nest Framework",
      "runtimeExecutable": "npm",
      "runtimeArgs": ["run", "start:dev"],
      "cwd": "${workspaceFolder}",
      "sourceMaps": true,
      "console": "integratedTerminal",
      "env": {
        "LOG_TYPE": "console"
      }
    }
  ]
}
```

作成後、VS Code の「実行とデバッグ」から **`Debug Nest Framework`** を選択し、NestJS アプリが正常に起動することを確認してください。

### 7. Git リポジトリの再設定

既存のリモート設定をリセットし、新しいリポジトリ紐付けを行います。

```bash
git remote rename origin old-origin
git remote rm old-origin
git remote add origin <新しいリポジトリURL>
git add .
git commit -m "initial commit"
git push -u origin main
```
