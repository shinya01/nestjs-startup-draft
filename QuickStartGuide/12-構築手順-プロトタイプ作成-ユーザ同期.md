# 12 - 構築手順 - 認証ユーザーのDB登録・同期

> ✅ 外部IdP（Cognito/Auth0等）の認証成功後、アプリケーションDBにユーザーが存在しなければ自動登録（JITプロビジョニング）し、アプリ固有のユーザーIDを払い出す仕組みを構築します。

---

## 🎯 目的

外部IdPから渡されるのは「一意な文字列（`sub`）」です。これをアプリ内のリレーショナルデータベースで扱いやすくするため、内部的な `SERIAL ID` 等に紐付け、`req.user` で常に内部IDを参照できるようにします。

---

## 🛠️ UserService の拡張

外部ID（`sub`）をキーにユーザーを検索・作成するメソッドを追加します。

```ts
// src/user/user.service.ts (抜粋)
@Transactional()
async findOrCreateByExternalId(externalId: string, email: string): Promise<UserDto> {
  let user = await this.userRepo.findByExternalId(externalId);
  
  if (!user) {
    this.logger.log(`New user detected. Registering: ${email}`);
    user = await this.userRepo.save({
      externalId,
      email,
    });
  }
  
  return plainToInstance(UserDto, user, { excludeExtraneousValues: true });
}
```

---

## 🔑 JwtStrategy での同期ロジック

`validate` メソッド内で、トークンの検証後にDBとの同期を行います。

```ts
// src/auth/strategies/cognito.strategy.ts (抜粋)
async validate(req: Request, payload: Claim): Promise<AuthUser> {
  const sub = payload.sub;

  // 1. まずはDBを確認（パフォーマンスのため）
  let user = await this.userService.findByExternalId(sub).catch(() => null);

  // 2. DBにいなければ、Cognitoから詳細情報を取得して登録
  if (!user) {
    const client = new CognitoIdentityProviderClient({ region: 'ap-northeast-1' });
    const token = ExtractJwt.fromAuthHeaderAsBearerToken()(req);
    
    const command = new GetUserCommand({ AccessToken: token });
    const response = await client.send(command);
    
    const email = response.UserAttributes?.find(a => a.Name === 'email')?.Value;
    if (!email) throw new InvalidTokenException();

    user = await this.userService.findOrCreateByExternalId(sub, email);
  }

  // 3. 以降、Controllerでは req.user.userId で内部IDが利用可能
  return {
    userId: user.id,
    sub: payload.sub,
    iss: payload.iss,
  };
}
```

## 💡 応用：カスタムデコレーターの作成

コントローラーで `req.user.userId` と書く代わりに、専用のデコレーターを用意するとコードが綺麗になります。

```ts
// src/common/decorators/current-user.decorator.ts
import { createParamDecorator, ExecutionContext } from '@nestjs/common';

export const CurrentUserId = createParamDecorator(
  (data: unknown, ctx: ExecutionContext) => {
    const request = ctx.switchToHttp().getRequest();
    return request.user?.userId; // JwtStrategyでセットした値
  },
);
```

### コントローラーでの使用例

```ts
@Get('me/profile')
getProfile(@CurrentUserId() userId: number) {
  return this.userService.getById(userId);
}
```

---

## ✅ 実装のポイント

- **依存関係の解決**: `AuthModule` で `UserModule` を `imports` し、`UserService` を注入できるようにします。
- **JITプロビジョニング**: ユーザーが初めてログインした瞬間にDBレコードが生成されるため、事前のユーザー登録機能（サインアップ画面）の実装を省略できます。
- **トランザクション**: `findOrCreateByExternalId` に `@Transactional()` を付与することで、不完全なユーザーデータが作成されるのを防ぎます。
