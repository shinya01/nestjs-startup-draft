# 09-構築手順 - 認証ユーザーのDB登録・同期

## 🎯 目的

外部IdP（例：Auth0, Cognito, Azure ADなど）からJWTトークンを受け取ったあと、  
そのユーザー情報をアプリケーションのDBに登録・同期して、アプリ内で管理できるようにするよ！

---

## 🧩 実装の流れ

1. `UserService` に「ユーザーを検索・作成するメソッド」を追加  
2. `JwtStrategy` の `validate()` メソッド内でDB同期を実行  
3. 必要に応じて `createdAt` や `lastLoginAt` などのメタ情報も更新

---

## 🛠️ 1. `UserService` に同期処理を追加

```ts
// user.service.ts
async findOrCreateByExternalId(sub: string, email: string): Promise<User> {
  let user = await this.userRepo.findByExternalId(sub);
  if (!user) {
    user = await this.userRepo.save({
      externalId: sub,
      email,
      createdAt: new Date(),
      lastLoginAt: new Date(),
    });
  } else {
    user.lastLoginAt = new Date();
    await this.userRepo.save(user);
  }
  return user;
}
```

> 💡 `externalId` はJWTの `sub` を使うのが一般的だよ！

---

## 🧩 2. `UserRepository` に検索メソッドを追加

```ts
// user.repository.ts
async findByExternalId(sub: string): Promise<User | null> {
  return this.findOne({ where: { externalId: sub } });
}
```

---

## 🧾 3. `User` エンティティにフィールドを追加

```ts
// user.entity.ts
@Entity()
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column({ unique: true })
  externalId: string;

  @Column()
  email: string;

  @Column({ type: 'timestamp', nullable: true })
  createdAt: Date;

  @Column({ type: 'timestamp', nullable: true })
  lastLoginAt: Date;
}
```

---

## 🔑 4. `JwtStrategy` で同期を実行

```ts
// jwt.strategy.ts
async validate(payload: Claim): Promise<any> {
  const sub = payload.sub;
  const email = payload.email;

  const user = await this.userService.findOrCreateByExternalId(sub, email);

  return {
    userId: user.id,
    email: user.email,
    roles: payload['cognito:groups'] || [],
  };
}
```

> 💡 `JwtStrategy` に `UserService` を注入するには、`forwardRef` を使う必要があるよ！

---

## 🧩 5. `auth.module.ts` で `UserModule` を `forwardRef` で読み込む

```ts
import { forwardRef, Module } from '@nestjs/common';
import { UserModule } from '../user/user.module';

@Module({
  imports: [PassportModule, forwardRef(() => UserModule)],
  providers: [JwtStrategy, JwtAuthGuard],
  exports: [JwtAuthGuard],
})
export class AuthModule {}
```

---

## 🧩 6. `user.module.ts` で `AuthModule` を `forwardRef` で読み込む

```ts
import { forwardRef, Module } from '@nestjs/common';
import { AuthModule } from '../auth/auth.module';

@Module({
  imports: [TypeOrmModule.forFeature([User]), forwardRef(() => AuthModule)],
  providers: [UserService],
  exports: [UserService],
})
export class UserModule {}
```

---

## ✅ まとめ

この構成で、JWTトークンを受け取ったときに：

- DBに該当ユーザーがいなければ自動で登録！
- すでに存在する場合はログイン日時を更新！
- アプリ内でユーザーIDを使って処理ができる！

---

これで、**外部IdPのユーザーをアプリケーションのユーザーとして一元管理**できるようになるよ！
